# Bert's Business Plan (2026-10-19)

## Decision
**Product: a marketplace-seller profit toolkit.**
1. FREE browser-based fee/profit calculator comparing Etsy, eBay, Amazon, Depop, Vinted, Shopify etc. ("where should I sell this item?"). Static site on GitHub Pages ($0 hosting). Acts as the SEO/traffic funnel.
2. PAID toolkit (~$19): Google Sheets/Excel workbook with inventory, sales log, ad-spend ROAS, quarterly tax estimate. Sold via Payhip free plan (5% fee, no monthly cost) or Lemon Squeezy.

## Why
- Zero upfront cost; I can build all of it with code.
- Clear buyer (handmade/reseller sellers), clear pain (fees eat margins).
- Free tool -> trust + organic search traffic -> paid upsell.

## Competitors (from initial research, unverified vendor claims)
- Craftybase: free Etsy fee/pricing spreadsheets (strong free alternative; Etsy-only).
- Getly: Etsy profit/inventory tracker, Google Sheets, $15.
- Payhip/Etsy listings: bundled trackers incl. tax/ROAS/cash flow.
- Gap/differentiator: multi-marketplace comparison + always-current fee data + instant web UI (no spreadsheet needed).

## Risks
- Fee data goes stale -> must verify each marketplace's official fee page before publishing and show "last updated".
- Etsy digital category is crowded; need niche listing titles.
- Revenue figures in blogs are marketing; expect slow start, distribution is the hard part.

## Costs / approvals needed
- Domain (~$10-15/yr) -> needs user approval.
- Everything else free tier.

## Domain candidates (DNS check only, not confirmed available)
sellermargin.io, marginmate.co, feecalc.shop, sellerfees.io
(sellermargin.com, profitpeg.com, listingmargin.com appear taken)

## Next steps
1. Verify current official fees per marketplace.
2. Build calculator (static HTML/JS) in /site.
3. Create GitHub repo + Pages.
4. Build paid workbook.
5. Brand + social handles, launch posts.

## Update 2026-10-19: Skeptic review -> narrow pivot
- Calculator niche is crowded (Voolist, Underpriced, Checkoutpage, etc.). No audience = biggest risk.
- Decision: do NOT buy a domain until the calculator shows traction (target: 100 users + email signups in 2 weeks of posting in seller communities).
- Verify all fees incl. Etsy Offsite Ads (added as unverified option). Add disclaimer (done).
- Fallback if no traction: CSV-export profit analyzer (upload Etsy/eBay order export -> true profit per SKU), sold as outcome, not template.
- Avoid marketplace names in brand/domain; nominative use only.
